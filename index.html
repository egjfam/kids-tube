📺 허용 채널 목록

· 여기 있는 채널의 영상만 목록·추천·다음 영상에 나오고, 그 외 영상은 재생되지 않아요.
· 채널 ID 얻는 법: 유튜브 앱에서 채널 열기 → 채널 이름 아래 설명(＞) 누르기 → 맨 아래 채널 공유 → 채널 ID 복사. 주소가 youtube.com/channel/UC… 형태면 주소를 그대로 붙여 넣어도 돼요. (@이름 주소는 인식 못 해요)
· 추천 비중: "많이"로 두면 그 채널 영상이 추천에 더 자주 나와요. "끔"은 잠시 숨기기(삭제 아님).

🧠 추천 방식

추천 = 허용 채널 영상만 섞어서 → 최신 영상 우선 + 은준이가 끝까지 잘 본 채널 우선 + 오늘 본 영상은 뒤로, 금방 꺼버린 영상은 덜 나오게 + 같은 채널이 3개 이상 연달아 나오지 않게.
